# BiliSearch Fixer

> LSPosed 模块：在 B 站官方客户端里过滤搜索结果的无关视频、广告卡和买量卡。只改搜索内容。

![build](https://github.com/xiaoancute/bili-search-fixer/actions/workflows/build.yml/badge.svg)

## 功能

| 能力 | 说明 |
|---|---|
| 搜索过滤 | 综合搜索 + 分类搜索（视频 / 用户 / 直播等 Tab） |
| 广告清理 | `CM` / `PURCHASE` / `goto=ad` 直接删除 |
| 相关性过滤 | 按标题和简介的关键词覆盖率评分；高亮辅助加分，UP 主不参与自动评分 |
| 搜索框规则 | `-排除词` / `#标签` / `@UP主` |
| 结果整理 | 最低播放量、屏蔽词、屏蔽 UP、白名单、标题去重、只保留视频、隐藏推荐卡、本地重排 |
| 过滤强度 | 宽松 / 标准 / 严格三档 |
| 运行状态 | Hook 上报、累计与最近一批结果的删除数、原因分类及最多 5 条被删视频示例 |
| 规则试算 | 用搜索词、标题和 UP 主 / mid 预览白名单、屏蔽词和屏蔽 UP 的命中结果 |

只 Hook 搜索响应，不改宿主 UI、不改请求、不发额外网络请求。

宽松允许部分关键词或仅简介匹配；标准和严格要求标题匹配。标题高亮不会直接放行，严格档仍会检查关键词覆盖程度。播放量只用于最低播放量限制和可选重排。

「状态」页按广告 / 商品、推荐卡、屏蔽规则、播放量、去重、相关性等原因统计最近一批删除结果，并展示少量被删标题和中文解释。翻页或切换 Tab 会产生新的一批结果；再次搜索后，旧记录会被替换。

「规则」页的试算只检查已保存的白名单、屏蔽词和屏蔽 UP。白名单按搜索词包含匹配，并会跳过该次搜索的所有本地过滤；屏蔽词检查标题，屏蔽 UP 按名称包含或 mid 匹配。只有标点或空白的规则不会匹配，也会在试算结果中提示。

## 规则语法

搜索词里可以直接带：

```
摄影 -入门 #ai @影视飓风
```

| 语法 | 行为 |
|---|---|
| `词` | 标题必须包含 |
| `-词` | 标题包含即删 |
| `#词` | 标签必须包含；App 响应没有 tag，回退到简介 |
| `@词` | 作者匹配任一 |

无修饰词时只跑自动相关性；出现任一修饰词后进入严格模式，普通词必须全部出现在标题。

## 安装

1. Android 9+，安装 LSPosed（Modern API 102）或 NPatch。
2. 安装 APK。
3. 在框架里启用模块，作用域勾选「哔哩哔哩」(`tv.danmaku.bili`)。
4. 强制停止并重启 B 站，搜索一次。
5. 打开模块 App 的「状态」页，显示「搜索过滤已生效」即正常。

日志：

```bash
adb logcat | grep BiliSearchFixer
```

## 已知限制

- 搜索卡片没有 tag 字段，`#` 规则只能匹配简介。
- 搜索卡片没有发布日期，无法按时间排序。
- 底部「相关搜索」是独立区块，当前不覆盖。
- 搜索词仍原样发给 B 站，`-排除词` 只在本地生效。
- 仅适配 B 站 9.0+；实测 9.16.1。
